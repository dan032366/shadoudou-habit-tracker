# 🌱 傻豆豆的打卡日常

一个零依赖的纯静态打卡网站：新增项目（如喝水 8 杯、跑步 5 公里、阅读 30 分钟），每天填写实际值并打钩完成；月历查看每天完成情况；系统自动给出每日评价与月度评价。

## 在线访问

- GitHub Pages：<https://dan032366.github.io/shadoudou-habit-tracker/>
- 仓库地址：<https://github.com/dan032366/shadoudou-habit-tracker>
- iPhone 安装：用 Safari 打开上面的 Pages 地址 → 分享 → 添加到主屏幕（详见 `iOS安装说明.txt`）

## 运行方式

- 直接双击 `index.html` 即可在浏览器中打开；
- 或启动一个本地静态服务器（更稳定）：

  ```bash
  python -m http.server 8000
  ```

  然后访问 <http://localhost:8000>。

## 功能

- 新增 / 编辑 / 删除项目（名称、每日目标、单位、古风图标或本地上传图片、可选需要完成的天数，默认无限），支持拖拽排序（触屏设备使用上移 / 下移按钮）；设置天数后项目从创建日起持续该天数，期间显示"已维持 x/N 天"，达到天数即标记已完成，结束日期之后不再显示该项目；在未来日期新增项目时，项目从所选日期开始
- 每日打卡：填写实际值，达到目标自动打钩，也可手动打钩；修改数值后会按当前数值重新判断是否完成
- 月历：每天显示"完成 n/N"，全部完成 / 部分完成 / 未打卡三种样式；点击历史日期可补记，未来日期只读
- 每日评价与月度评价：按完成率自动生成鼓励或夸奖文案
- 月度完成率 = 当月完成全部计划的天数 ÷ 当月已有计划且已到来的天数（无计划或未到来的日子不计入）
- 数据保存在浏览器 localStorage（键名 `habit-tracker.v1`），无需服务器

## 技术说明

- 纯 HTML + CSS + JavaScript，无构建步骤、无第三方依赖
- 日期使用浏览器本地时区
- 删除项目仅标记为已删除，历史打卡记录保留
- 界面采用古风配色（宣纸底、墨色文字、朱砂点缀、楷体字族），支持跟随系统的深色模式

## 打包为 exe

项目自带打包工程（`pack/`），运行 `pack\build.bat` 即可重新生成 `傻豆豆的打卡日常.exe`：

- 双击 exe 即打开应用窗口，无需安装任何运行环境
- exe 内置微型本地服务器，页面以 Edge 应用窗口显示；存档保存在系统目录 `%LOCALAPPDATA%\ShadoudouHabit\data.json`，无论启动端口如何变化都能完整保留
- 点击关闭后程序直接退出，不驻留系统托盘；页面左上角会显示"已保存"状态
- 若电脑没有 Edge（Win10/11 默认自带），会自动改用系统默认浏览器打开
