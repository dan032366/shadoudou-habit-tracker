傻豆豆的打卡日常 - iPhone 安装说明
====================================

这是一个 PWA（渐进式网页应用）安装包。iPhone 无需越狱、无需 Apple 开发者账号，即可把应用"安装"到主屏幕，像原生 App 一样全屏使用。

【安装步骤】
1. 先把本文件夹部署到一台能通过网络访问的服务器（部署方法见下）。
2. 用 iPhone 自带的 Safari 浏览器打开部署后的网址。
3. 点击 Safari 底部（或顶部）的"分享"按钮（方框 + 向上箭头）。
4. 选择"添加到主屏幕"。
5. 确认应用名"傻豆豆打卡"后点"添加"。
6. 主屏幕出现应用图标，点击即可像 App 一样全屏使用。

【如何部署（任选其一）】

方式一：局域网部署（最快，适合自用）
- 在电脑上进入本文件夹，打开命令行运行：
    python -m http.server 8000 --bind 0.0.0.0
- 让 iPhone 和电脑连接同一个 Wi-Fi。
- 在电脑上运行 ipconfig 查看本机 IP（形如 192.168.x.x）。
- 用 iPhone 的 Safari 打开：http://你的电脑IP:8000
- 说明：此方式为 http，可正常"添加到主屏幕"和使用，但不支持离线缓存。

方式二：公网 HTTPS 部署（推荐，支持离线使用）
- 把本文件夹上传到任意支持 HTTPS 的静态托管平台（如 GitHub Pages、Netlify、Vercel、云服务器等）。
- 用 iPhone Safari 打开 HTTPS 网址，再按上面步骤添加到主屏幕。
- HTTPS 下会自动启用离线缓存，断网也能打开应用。

【数据说明】
- 打卡数据保存在 iPhone 当前浏览器的本地存储中（按网址隔离）。
- 请勿在 Safari 中清除该网站的数据；换设备或清除数据会导致记录丢失。

【备注】
- 真正的 .ipa 安装包（App Store / TestFlight）需要 Apple 开发者账号、Mac 电脑和 Xcode 签名，
  个人在 Windows 上无法直接生成。PWA 是 iPhone 上最接近原生 App 且免费的方案。
